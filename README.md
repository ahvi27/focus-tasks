# Focus — beginner task tracker

## Run
Extract the ZIP and double-click index.html to open it in your browser.
No npm, installation, internet connection, or backend is needed.
You can also open the folder in VS Code and use Live Server.

## Features
Add tasks, check them off, filter tasks, delete tasks, and clear completed tasks.
The page adapts to phones and desktops. Tasks are saved in browser localStorage.
Storage belongs to the current browser and origin; moving the file or changing browsers may show a different task list. If storage is blocked, a message explains that tasks are temporary.

## Learn by editing
- HTML: headings, sections, form, and list.
- CSS: layout, colors, spacing, and mobile media query.
- JavaScript: events, DOM creation, arrays, and localStorage.

Try changing the colors in :root, changing the heading, or adding a due date.
